## 2 · New findings — gaps as of today

### P0 — blocks safeguarding operations on Sunday

**G1. No UI exists to roster staff or set room capacity.**
`room_roster` and `room_staffing` (16 Aug migration) are admin-writable in
RLS but there is **no screen anywhere** that writes them. Consequence:
`can_access_room_roll()` returns false for every facilitator, so the roll
call at `/facilitate/roll/:room` shows "not rostered" to the very people it
was built for. Until a roster UI (or seed rows) exists, the child-safety
system cannot be operated by anyone but an admin running SQL.
*Fix: roster tab in the admin console (date, room, staff, duty, capacity).*

**G2. No UI for authorised collectors.**
The departure sheet offers guardians + pre-authorised collectors, but no
portal or staff-hub screen lets a guardian add them. Every child will show
"no collectors on record" at the door. The brief requires collectors to be
set in advance in the portal.
*Fix: collectors manager on PortalKids (guardian adds name/phone, revokes).*

**G3. No UI for the guardian-consent surfaces created on 16 Aug.**
`guardian_consents` (wall display), `profiles.wall_opt_out` and
`household_members.teen_self_signout` are enforced at write time — correctly
fail-closed — but there is no way for a guardian to grant consent or toggle
the settings. Net effect today: **no minor's name can ever appear on a wall,
and no teen can ever self-sign-out.** The handbook tells parents they can
change wall display "in the portal" — that is not yet true.
*Fix: consent + opt-out + self-sign-out controls on PortalKids/PortalSettings.*

**G4. No UI to manage concession requests.**
`/membership` inserts into `concession_requests`; nothing reads it. Requests
will accumulate invisibly. The annual counters exist, but a human needs a
queue to approve/decline.
*Fix: concession queue in the admin Members tab.*

**G5. `generate-video-questions` has no retry or fallback.**
DeepSeek's `data_inspection_failed` content filter (hit live this week)
hard-fails generation with no recovery path. One retry + Gemini fallback
(`GOOGLE_AI_API_KEY` is set) closes it.

### P1 — should land before the first members-only Sunday

**G6. No rate limiting anywhere.** Q&A inserts into `session_responses`,
trial-ticket issuance, and `nfc-checkin` all accept unbounded anonymous or
member traffic. Trial issuance is one-per-email (good) but nothing stops an
IP hammering it. *Fix: per-IP/per-user windows on the three public paths.*

**G7. Trial pass delivery and follow-up are unbuilt.** The pass renders as a
QR on screen only — no branded email delivery, and no single post-session
follow-up email (charter commitment). Both belong in the `notify-outbox`
template set.

**G8. Data export is missing.** `delete-account` exists and is wired into
PortalSettings; there is no export-my-data path anywhere. Privacy law and the
overhaul brief both expect it.

**G9. Guardian departure emails depend on a facilitator's phone being awake.**
The outbox drains when the roll UI flushes; a sleeping/closed phone means
emails sit. A pg_cron backstop is now documented
(`20260819150000_cron_notify_outbox.sql`) but must be **registered in the
dashboard** with `CRON_SECRET` set — treat as a launch checklist item.

**G10. Brief-absence escalation is client-side only.** The 10-minute
overdue alert fires from the roll page's timer. If the page is backgrounded,
nothing escalates. A server sweep of `brief_absence` older than 10 minutes
(same cron pattern) would make it bulletproof.

**G11. Testing depth.** 194 unit tests + anon RLS smoke pass, but: no
per-role RLS tests (member/facilitator/guardian JWT probes — the
highest-value suite per the brief), no Playwright critical paths (signup,
subscribe, cancel, check-in, training module, leave, document assignment),
no timezone DST tests.

**G12. Supabase auth emails are unbranded.** Reset-password, magic link,
signup confirmation etc. still use Supabase defaults. The shared brand layout
exists in `notify-outbox`; the auth templates need it (Dashboard → Auth →
Email Templates).

### P2 — hygiene and debt

**G17. Feature-first restructure (`src/features/…`) deferred** during the
