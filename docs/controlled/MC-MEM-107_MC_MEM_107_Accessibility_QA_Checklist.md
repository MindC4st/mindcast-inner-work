> ♿ **DRAFT QA CHECKLIST**
- [ ] All interactive elements usable by keyboard.
- [ ] Visible focus states.
- [ ] Form controls have labels and understandable errors.
- [ ] Images have appropriate alt text or are marked decorative.
- [ ] Text/background contrast reviewed.
- [ ] Zoom/text enlargement does not break core flows.
- [ ] Motion/animation does not block access; reduced-motion behaviour reviewed.
- [ ] Screen-reader order checked on signup, portal, live join and admin training.
- [ ] Headings and landmarks are logical.
- [ ] Touch targets workable on mobile.
- [ ] Captions/transcripts considered for required training/session video.
